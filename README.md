# Dominion Kingdom Picker

[Use the app here](https://irampton.github.io/dominion-card-picker/).

Choose ten random Kingdom cards from the sets and editions you own. Customize your game with complex requirements and save presets. Includes landscapes; swapping single cards, locking favorites, and seeing what extra cards and materials you need.

Have feedback, a bug report, or an idea? Please [open a GitHub issue](https://github.com/irampton/dominion-card-picker/issues).

An unofficial companion for Dominion, by Donald X. Vaccarino / Rio Grande Games.
